# Classtrack

Classtrack is a RESTful API server for managing sports classes at a sports complex.
Built with NestJS and TypeScript, it enables user registration, role-based access (user/admin), and comprehensive sports class management.

Users can browse, filter, and apply for sports classes such as baseball, basketball, and football.
Admins can manage all aspects of classes—including scheduling, editing, and viewing enrolled users—through secure endpoints.
The API is fully documented with Swagger and uses a PostgreSQL database for persistent storage.
